# 📑 마크다운(Markdown) 실전 가이드라인

### 1. 제목 계층 설정 (Headers)
가장 먼저 `#` 기호를 사용하여 문서의 구조를 잡는다. 
`#`의 개수가 많아질수록 글씨 크기는 작아지며, 보통 `##`나 `###`를 사용하여 주요 섹션을 구분한다. 
각 섹션 사이에는 적절한 여백을 두는 것이 좋다.

---

### 2. 텍스트 강조와 스타일 (Emphasis)
중요한 키워드는 단어 양옆에 별표 두 개를 붙여 **굵게 강조**하거나, 별표 하나를 붙여 *기울임* 처리를 할 수 있다. 
문장 중간에 취소선을 긋고 싶다면 물결표 두 개를 사용해 ~~삭제된 내용~~처럼 표현.
*   **굵게:** `**텍스트**`
*   **기울임:** `*텍스트*`
*   **구분선:** 하이픈 세 개 `---` (섹션을 나눌 때 시각적으로 매우 편안.) 아니면 `***`이나 `___`도 가능

---

### 3. 하이퍼링크와 이미지 연결 (Links & Images)
텍스트 파일에서 불가능했던 링크 활성화를 위해 `[표시할 문구](URL주소)` 형식을 사용한다. 
예를 들어 [내 깃허브 프로필](https://github.com)과 같이 작성하면 깔끔한 하이퍼링크가 생성된다. 
이미지를 보여주고 싶다면 링크 맨 앞에 `!`를 붙여 `![설명](이미지경로)`로 작성한다.
*   **외부 링크:** `[표시할 문구](URL)`
*   **이미지 삽입:** `![이미지 설명](이미지 주소나 경로)`
    > **꿀팁:** 깃허브 Issue나 Pull Request 작성 창에 이미지를 드래그 앤 드롭하면 자동으로 이미지 링크 주소가 생성된다.
    > 그걸 복사해서 `.md` 파일에 붙여넣으면 편하다.

---

### 4. 코드 블록과 문법 강조 (Code Blocks)
코드나 설정값을 공유할 때는 백틱 세 개(```)를 사용한다. 
시작하는 백틱 옆에 `python`, `sql`, `c` 등 언어 이름을 적으면 아래와 같이 해당 언어에 맞는 색상이 입혀진다.

```python
def welcome():
    print("마크다운 가이드에 오신 것을 환영합니다!")
```

```json
    { "상태": "성공", "메시지": "색깔이 들어간 것처럼 보인다." }
 ```
---

### 5. 깔끔한 리스트와 체크박스
단순한 점 나열 외에도 업무 진행 상황을 보여줄 때 유용하다.
*   **순서 없는 목록:** `*` 또는 `-`를 사용.
*   **체크박스:** `- [ ]` (미완료), `- [x]` (완료)를 입력하면 깃허브에서 클릭 가능한 체크박스가 생긴다.
    *   - [x] 환경 설정 완료
    *   - [ ] 첫 번째 기능 구현
