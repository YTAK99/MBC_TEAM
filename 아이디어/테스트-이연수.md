풀스크린 랜딩 페이지(Full-screen Landing Page)
사용자가 사이트 주소를 치고 들어왔을때 모니터 화면 전체를 하나의 포스터나 잡지표지처럼 채우는 방식

- 장점: 사용자가 우리가 보여주고 싶은 핵심 메세지에만 온전히 집중할 수 있음 (시선 분산 방지, 명확한 사용자 흐름 케어; 로그인이 되어 있다면 게시판 화면으로, 로그인 전이면 로그인 화면으로 )
- 단점: 반응형 페이지 어려움. 꽉찬 화면을 기준으로 레이아웃을 잡기때문에 화면 크기가 작아지면 버튼이 화면 밖으로 밀려나는 현상 발생
  화면이 밍밍하게 보일수있는 우려

풀스크린 랜딩 페이지의 3대 필수 구성요소
헤드라인 : 사이트가 뭔지 알려주는 문장/ 혼자하면 어렵지만, 함께하면 쉬워진다? Class Q
서브카피 : 헤드라인을 보조하는 짧은 설명/ 코딩하다 막히는 순간, 동료들과 강사님이 함께 문제를 해결하는 공간입니다.
CTA버튼 : 사용자의 행동을 유도하는 버튼/ [나도 질문하러 가기]
