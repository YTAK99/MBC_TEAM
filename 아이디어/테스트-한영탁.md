1. 회원가입(signup)이 실제로 동작하지 않음
signup 뷰가 POST를 처리하지 않고, 빈 폼만 렌더링합니다.

def signup(request):
    form = SignupForm()
    return render(request, "registration/signup.html", {"form": form})
템플릿도 {{ form }} 대신 수동 input을 쓰고 있어, merge 이전부터 미완성 상태로 보입니다. 로그인·게시판·상세는 문제없고, 회원가입만 깨져 있습니다.

2. 사이드바 “인기 질문” 링크 값 불일치
base.html은 ?sort=likes인데, 뷰는 sort=popular만 인식합니다.

      <a href="{% url 'questions:board' %}?sort=likes" class="classq-sidebar-link">
→ 인기 정렬이 적용되지 않고 최신순으로 보일 수 있습니다.

3. 강사 게시판(teacher_board)에서 상태 필터가 페이지 이동 시 사라짐
뷰는 status로 필터링하지만, context에 status_filter를 넘기지 않습니다.
페이지네이션·정렬 링크에도 status가 빠져 있습니다.
?status=OPEN으로 들어온 뒤 2페이지·정렬 변경 시 필터가 풀릴 수 있습니다. (태그 URL 생성 로직에는 status가 포함되어 있음)

4. 질문 작성(ask)에 태그 선택 없음
게시판에서는 태그 필터를 쓰지만, QuestionForm/ask.html에는 태그 필드가 없습니다. 의도된 설계일 수 있으나, “태그로 분류된 질문”을 쓰려면 admin이나 추후 폼 추가가 필요합니다.

merge 관련 결론
다른 파일에는 merge로 인한 깨진 코드는 없습니다. urls.py, forms.py, models.py, 템플릿, admin.py는 현재 views.py와 맞습니다.

우선순위로 고치려면:

1.회원가입 POST 처리 (가입이 필요할 때)
2.sort=likes → sort=popular
3.강사 게시판 status 유지 (강사 화면을 쓸 때)
